# Тиры Skif

Тиры отключены, пока в окружении не заданы все четыре значения: `TIER_GUILD_ID` (по умолчанию берётся из `GUILD_ID`), `TIERCHECK_ROLE_ID`, `TIER_1_ROLE_ID`, `TIER_2_ROLE_ID`, `TIER_3_ROLE_ID`. Это ID вашего сервера и ролей — скопируйте их из Discord (режим разработчика → «Копировать ID») в `.env`.

После настройки при старте бота в категории SKIF • СОСТАВ автоматически появляются три канала: повышение-на-тир-1/2/3. Родительские каналы видны семье, личная заявка — автору и участникам с ролью tiercheck. Администраторы Discord сохраняют обычный доступ.

Форма: ник/возраст/статик, откаты ГГ, каптов, МЦЛ и причина запроса. МЦЛ обязательны для тиров 1 и 2, для тира 3 необязательны. Тир определяет канал. Одна незакрытая заявка на все три тира. Проверяют только участники с ролью tiercheck (`TIERCHECK_ROLE_ID`), без исключений для старших ролей и администратора; собственную заявку одобрять нельзя.

При одобрении сначала добавляется выбранный тир, затем снимаются другие два тира, прочие роли не затрагиваются. Положение роли бота проверяется для всех тиров. Частично выполненная замена сохраняется как applying; после исправления прав нужно повторить одобрение. Отказать после начала замены нельзя.

Причина отказа обязательна. Результат сохраняется в ветке, базе и копии Discord; бот также пытается отправить ЛС. При недоступных ЛС проверяющий получает уведомление, а игрок читает результат в своей ветке. Заявки доступны в очереди Хай, /my_requests и истории тиров в карточке игрока.

Повторный запуск использует прежние каналы и панели. /setup для тиров не требуется.
