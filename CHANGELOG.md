# Изменения

## Сентябрь 2026
- Добавлен общий канал «профиль» с единой панелью для всех заявок (грины, варны, контракты, повышения, тиры). Новый модуль `bot/hub.py`.
- Тиры: добавлен `tier_channel()` для поиска канала по topic; заявки на тир теперь создаются в правильном канале независимо от источника.
- Прогрессия: `submit()` теперь использует канал «профиль» при его наличии, иначе — прежние каналы (обратная совместимость).
- Провижнинг: `/setup` теперь создаёт канал «профиль» и панель после установки тиров.
- Исправлено: не был включён Message Content intent, из-за чего бот не видел скриншоты в ветках контрактов, гринов и варнов. Intents вынесены в `make_intents()`, есть тест.
- Исправлено: `.env.example` указывал `data/bot.db`, а код по умолчанию использует `data/skif-v9.db`; пример приведён к коду.
- Исправлено: слэш-команды (включая /setup) не регистрировались при запуске, из-за чего Discord отвечал «Приложение не отвечает». Регистрация теперь в setup_hook, есть тест.
- Исправлено: кнопки «Сдача гринов» и «Снятие варнов» переставали работать после перезапуска бота (панели не были зарегистрированы).
- Единый список постоянных панелей `bot/registry.py` и тест, который ловит забытые кнопки.
- Устаревшие кнопки отвечают понятным текстом вместо «Ошибка взаимодействия».
- Понятные сообщения об ошибках Discord (лимиты, недоступность) и базы данных.
- Исправлены склейки в тексте панелей («планшета.Отчёт», «грина.Заявка»).
- Команды разбиты на четыре группы в `bot/commands.py`, цвета embed вынесены в `bot/theme.py`.
- `/health` показывает готовность бота и задержку Discord.
- Код отформатирован `ruff format`, `ruff check` проходит без замечаний.
- CI: проверка форматирования, запуск на Python 3.12 и 3.13 (3.13 не блокирует), Dependabot, pre-commit.
- Убраны дубли тестов и неиспользуемые файлы, обновлены README и документация.
